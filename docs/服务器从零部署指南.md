# 在租用的服务器上从零部署（外网可访问）

目标：把项目放到你租的服务器上跑，**网站和爬虫都在服务器运行**，你在任何地方用浏览器打开 **http://服务器公网IP:5050** 就能查看线索。

---

## 第一步：租一台服务器并拿到登录方式

### 1.1 选哪家、选什么配置

- **国内**：阿里云、腾讯云、华为云 等，选「云服务器 ECS」或「轻量应用服务器」。
- **国外**：DigitalOcean、Vultr、Linode 等。

建议配置：**1 核 1G 内存** 即可，系统选 **Ubuntu 22.04**（或 20.04）。

### 1.2 拿到这三样

买好后在控制台里记下：

| 项目 | 说明 |
|------|------|
| **公网 IP** | 例如 `123.45.67.89`，外网访问网站用这个 |
| **登录用户** | 常见是 `root` 或 `ubuntu` |
| **登录方式** | 密码 或 SSH 密钥（.pem 文件） |

---

## 第二步：用 SSH 连上服务器

在你**自己的电脑**上操作（Mac 用「终端」，Windows 用「PowerShell」或「终端」）。

把下面命令里的 `你的公网IP`、`ubuntu` 换成你的实际 IP 和用户名：

```bash
ssh ubuntu@你的公网IP
```

- 第一次会问 `Are you sure you want to continue connecting?` 输入 **yes** 回车。
- 若是密码登录，会提示输入密码（输入时不会显示，输完回车）。
- 若是密钥登录（.pem），用：  
  `ssh -i /路径/你的密钥.pem ubuntu@你的公网IP`

连上后，终端前面会变成 `ubuntu@xxx:~$`，表示已经进入服务器。

---

## 第三步：把项目代码放到服务器上

任选一种方式。

### 方式 A：项目已在 GitHub / Gitee

在服务器上（SSH 连上后）执行：

```bash
# 安装 git（若没有）
sudo apt update && sudo apt install -y git

# 选一个目录，克隆项目（把地址换成你的仓库地址）
cd ~
git clone https://github.com/你的用户名/你的仓库名.git
cd 你的仓库名
# 若项目在子目录 crawler，再执行： cd crawler
```

若项目就在仓库根目录且名字叫 `crawler`，可能类似：

```bash
cd ~
git clone https://github.com/xxx/nptune.git
cd nptune/crawler
```

后面所有「项目根目录」都指这个 `crawler` 目录。

### 方式 B：从本机上传（未用 Git）

在你**自己的电脑**上，在项目**上一级**目录执行（把 `你的IP`、`ubuntu` 换成实际值）：

```bash
scp -r crawler ubuntu@你的IP:~/
```

上传后，在服务器上会有 `~/crawler`，即项目根目录。

---

## 第四步：在服务器上安装 Python 与依赖

在 **服务器** 的终端里执行（路径按你第三步实际目录改，这里用 `~/crawler`）：

```bash
cd ~/crawler

# 安装 Python 3.10 和 venv（Ubuntu 22 一般自带，没有就装）
sudo apt update
sudo apt install -y python3 python3-venv python3-pip

# 创建虚拟环境并安装依赖
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

看到 `Successfully installed ...` 即成功。

---

## 第五步：在服务器上配置 .env

在服务器上，项目根目录下：

```bash
cd ~/crawler
nano .env
```

（没有 `.env` 就先复制：`cp .env.example .env` 再 `nano .env`）

至少配置这几项（按需修改）：

```env
# 网页登录（必配，否则用默认账号密码）
WEB_LOGIN_USER=Sylicora
WEB_LOGIN_PASSWORD=你的密码

# 端口（保持 5050 即可）
PORT=5050

# 爬虫用（要爬 Upwork 就填）
APIFY_API_TOKEN=你的Apify的token

# Telegram 推送（可选）
# TELEGRAM_BOT_TOKEN=xxx
# TELEGRAM_CHAT_ID=xxx
```

保存：`Ctrl+O` 回车，退出：`Ctrl+X`。

若你本机已有配好的 `.env`，也可以在本机执行 `scp .env ubuntu@你的IP:~/crawler/` 上传覆盖（注意别把本机密钥泄露）。

---

## 第六步：开放服务器端口（否则外网访问不了）

云厂商有「安全组」或「防火墙」，需要放行 **5050** 端口。

- **阿里云**：控制台 → 实例 → 安全组 → 配置规则 → 入方向 → 添加：端口 5050，来源 0.0.0.0/0。
- **腾讯云**：控制台 → 防火墙 → 添加规则：端口 5050，来源 0.0.0.0/0。
- **DigitalOcean / Vultr**：创建 Droplet 时或之后在 Firewall 里放行 5050。

这样你才能从外网用 `http://公网IP:5050` 打开网站。

---

## 第七步：在服务器上启动网站并测试外网访问

在**服务器**上：

```bash
cd ~/crawler
source .venv/bin/activate
gunicorn -w 2 -b 0.0.0.0:5050 "src.web.app:app"
```

不要关这个终端。在你**自己的电脑**浏览器里打开：

**http://你的公网IP:5050**

例如：`http://123.45.67.89:5050`

能看到登录页、用第五步的账号密码登录进去，说明**网站已在服务器跑起来且外网可访问**。  
测试完后在服务器上按 `Ctrl+C` 停掉 gunicorn，接着做第八步让它开机自启。

---

## 第八步：让网站开机自启（systemd）

这样服务器重启后网站也会自动起来，不用再手动运行 gunicorn。

在服务器上执行（**把 `ubuntu` 和 `/home/ubuntu/crawler` 换成你的用户名和实际路径**）：

```bash
sudo nano /etc/systemd/system/neptune-web.service
```

写入下面内容（路径按你的改）：

```ini
[Unit]
Description=NepTune 线索网站
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/crawler
Environment=PATH=/home/ubuntu/crawler/.venv/bin
Environment=PORT=5050
ExecStart=/home/ubuntu/crawler/.venv/bin/gunicorn -w 2 -b 0.0.0.0:5050 "src.web.app:app"
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

保存退出后执行：

```bash
sudo systemctl daemon-reload
sudo systemctl enable neptune-web
sudo systemctl start neptune-web
sudo systemctl status neptune-web
```

看到 `active (running)` 就表示服务已常驻。之后你随时用 **http://公网IP:5050** 即可从外网访问。

---

## 第九步：部署后立刻爬 100 条（可选）

在服务器上再开一个 SSH 会话（或先 `Ctrl+C` 停掉之前的测试 gunicorn 后在同一终端执行）：

```bash
cd ~/crawler
source .venv/bin/activate
python -m src.run upwork
```

首次会爬约 100 条并写入数据库；若配了 Telegram 会推送一条汇总。
刷新 **http://公网IP:5050** 的「线索总览」即可看到数据。

---

## 第十步：每天早上 9 点自动爬一次（可选）

在服务器上执行：

```bash
crontab -e
```

选一个编辑器（如 nano），在文件末尾加一行（**把路径改成你的**，例如 `/home/ubuntu/crawler`）：

```cron
0 9 * * * cd /home/ubuntu/crawler && .venv/bin/python -m src.run upwork >> /home/ubuntu/crawler/logs/cron.log 2>&1
```

先建日志目录：

```bash
mkdir -p ~/crawler/logs
```

保存退出。之后每天 9 点（服务器时区）会自动跑一次爬虫。若要用中国时间，可在 crontab 那行前面加：`TZ=Asia/Shanghai`（具体写法可查 crontab 时区）。

---

## 小结：你要记住的

| 目的 | 操作 |
|------|------|
| **外网访问网站** | 浏览器打开 **http://你的公网IP:5050**，用 .env 里配置的账号密码登录 |
| **改登录密码** | 在服务器上改 `~/crawler/.env` 里的 `WEB_LOGIN_PASSWORD`，然后 `sudo systemctl restart neptune-web` |
| **看网站是否在跑** | 在服务器执行 `sudo systemctl status neptune-web` |
| **重启网站** | `sudo systemctl restart neptune-web` |
| **手动爬一次** | `cd ~/crawler && source .venv/bin/activate && python -m src.run upwork` |

全部做完后：**网站和爬虫都在服务器跑，你不再在本地跑；用外网打开 http://公网IP:5050 即可查看结果。**  
若以后要绑域名或上 HTTPS，可再按 [DEPLOY.md](DEPLOY.md) 里的 Nginx 部分配置。
