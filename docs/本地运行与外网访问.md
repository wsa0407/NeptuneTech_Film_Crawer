# 从零开始：本地运行 + 外网访问

按下面步骤做完后，你可以在本机打开网页，并得到一个**外网可访问的链接**（手机、别人电脑都能打开）。

---

## 第一步：确认本机环境

1. 打开**终端**（Mac：打开「终端」；Windows：打开「命令提示符」或 PowerShell）。
2. 确认已安装 **Python 3.10 或以上**：
   ```bash
   python3 --version
   ```
   若显示 `Python 3.10.x` 或更高即可。若未安装，请先到 [python.org](https://www.python.org/downloads/) 下载安装。

3. 进入项目根目录（即包含 `src` 文件夹、`requirements.txt` 的那个目录）：
   ```bash
   cd /Users/siang/Desktop/CHANSTURBO/NepTune/crawler
   ```
   Windows 用户把路径改成你自己的，例如：`cd D:\NepTune\crawler`。

---

## 第二步：安装依赖

在**同一终端**、**项目根目录**下执行：

```bash
# 创建虚拟环境（只需做一次）
python3 -m venv .venv

# 激活虚拟环境
# Mac / Linux：
source .venv/bin/activate
# Windows：
# .venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt
```

看到 `Successfully installed ...` 即表示安装成功。以后每次新开终端跑网站或爬虫前，都要先执行一次 `source .venv/bin/activate`（Windows 用 `.venv\Scripts\activate`）。

---

## 第三步：配置网页与端口

1. 在项目根目录下，若还没有 `.env` 文件，复制示例：
   ```bash
   cp .env.example .env
   ```
   Windows：`copy .env.example .env`

2. 用任意文本编辑器打开 `.env`，确认或修改这几项（没有就自己加一行）：

   | 配置项 | 说明 | 示例 |
   |--------|------|------|
   | `WEB_LOGIN_USER` | 登录账号 | `Sylicora` |
   | `WEB_LOGIN_PASSWORD` | 登录密码 | `JustGetItDone` |
   | `PORT` | 网站端口（外网访问时不要改） | `5050` |

   示例内容：
   ```
   WEB_LOGIN_USER=Sylicora
   WEB_LOGIN_PASSWORD=JustGetItDone
   PORT=5050
   ```

3. 保存 `.env` 后关闭。

---

## 第四步：启动网站（本机可访问）

在**已激活虚拟环境**的终端里执行：

```bash
cd /Users/siang/Desktop/CHANSTURBO/NepTune/crawler
source .venv/bin/activate   # Windows: .venv\Scripts\activate
python -m src.web.app
```

看到类似 `Running on http://0.0.0.0:5050` 就表示网站已启动。

- 在本机浏览器打开：**http://127.0.0.1:5050** 或 **http://localhost:5050**
- 用上面 `.env` 里的账号密码登录，能进入「线索总览」即表示网页配置正确。

**不要关这个终端窗口**，关掉网站就停了。外网访问需要再开一个终端做下一步。

---

## 第五步：让外网也能访问（Ngrok）

现在网站只在本机可访问。要让手机或别人通过互联网访问，需要把本机的 5050 端口「暴露」到公网，用 **ngrok** 即可。

### 5.1 下载并安装 ngrok

1. 打开：https://ngrok.com/download  
2. 按你的系统下载（Mac / Windows / Linux）。  
3. 解压得到 `ngrok`（或 `ngrok.exe`），可以：
   - 放到项目目录里，或  
   - 放到系统 PATH 里（如 Mac：`mv ngrok /usr/local/bin/`）。

### 5.2 注册并配置 token（免费）

1. 打开 https://dashboard.ngrok.com/signup 注册账号（可用 Google 登录）。  
2. 登录后打开：https://dashboard.ngrok.com/get-started/your-authtoken  
3. 复制你的 **Authtoken**。  
4. 在终端执行（把 `你的token` 换成刚复制的）：
   ```bash
   ngrok config add-authtoken 你的token
   ```

### 5.3 暴露 5050 端口

**新开一个终端窗口**（原来跑网站的终端保持不动），执行：

```bash
ngrok http 5050
```

会看到类似：

```
Forwarding   https://xxxx-xx-xx-xx-xx.ngrok-free.app -> http://localhost:5050
```

这里的 **https://xxxx-xx-xx-xx-xx.ngrok-free.app** 就是你的**外网访问地址**。

- 用手机浏览器或别人电脑打开这个链接，输入同样的账号密码即可登录。  
- 每次重新运行 `ngrok http 5050`，免费版链接可能会变；若需要固定域名，需用 ngrok 付费版或自己买域名。

## 第六步：可选——第一次爬 100 条线索

若你已配置 `.env` 里的 `APIFY_API_TOKEN`（用于 Upwork 爬取），可以在**再开一个终端**里执行一次爬取，往网站里灌入约 100 条数据：

```bash
cd /Users/siang/Desktop/CHANSTURBO/NepTune/crawler
source .venv/bin/activate
python -m src.run upwork
```

- 首次运行会爬约 100 条并写入本地数据库；
- 若配置了 Telegram，会推送一条汇总（完成时间、条数、soraplayground.com 链接）。  
- 刷新网页即可在「线索总览」等页面看到数据。

---

## 小结：你要记住的几件事

| 目的 | 操作 |
|------|------|
| 本机访问网页 | 终端 1：`source .venv/bin/activate` → `python -m src.web.app`，浏览器打开 http://127.0.0.1:5050 |
| 外网访问网页 | 终端 2：`ngrok http 5050`，用显示的 https 链接访问 |
| 改登录账号/密码 | 编辑 `.env` 里的 `WEB_LOGIN_USER`、`WEB_LOGIN_PASSWORD` |
| 改端口 | 改 `.env` 里 `PORT=5050`，启动命令不变；用 ngrok 时改成 `ngrok http 新端口` |

以后每次使用：

1. 终端 1：进入项目目录 → 激活虚拟环境 → `python -m src.web.app`  
2. 终端 2：`ngrok http 5050`  
3. 用本机地址或 ngrok 的 https 链接打开网站即可。

若你后面要放到正式服务器上、用固定域名，再按仓库里的 [docs/DEPLOY.md](DEPLOY.md) 操作即可。
